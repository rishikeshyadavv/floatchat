How it works

  1. Type your question in plain English — no SQL needed.
  2. The AI translates it into a read-only SQL query using Groq's Llama 3.3-70B (or Gemini as fallback).
  3. The query runs against the ARGO float database (DuckDB locally, TimescaleDB in Docker).
  4. Results return as a data table, with auto-generated depth/temperature charts and interactive maps.
  5. Safety first — destructive SQL (DROP, DELETE, ATTACH, etc.) is blocked; query logs are protected from exfiltration.

Set `GROQ_API_KEY` and/or `GEMINI_API_KEY` in `.env` for live LLM-powered SQL generation. Without API keys, the backend will process queries using the built-in sample data.
